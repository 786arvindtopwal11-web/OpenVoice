# Video notes (optional)

Kisi video ke liye bot ko extra jaankari deni ho (jaise poori script, sources,
ya kuch facts), to is folder mein `<VIDEO_ID>.md` naam se file banaiye.

Example: video link `https://www.youtube.com/shorts/AbC123xYz` hai, to file ka
naam hoga `AbC123xYz.md`.

Bot us video ke comments ka reply likhte waqt is file ko padhega. Isse reply
zyada sahi aur detail wale bante hain.
